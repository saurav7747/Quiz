# Fundamentals of Computing Quiz PWA

A lightweight, high-performance Progressive Web App (PWA) created purely with HTML5, CSS3, and Vanilla JavaScript.

## Features
- **500 Questions**: Includes 450 Multiple Choice Questions (MCQs) and 50 True/False Questions strictly copied from the question bank.
- **LocalStorage Persistence**: Auto-saves quiz progress. Refreshing the browser or returning later resumes from the last visited question.
- **PWA & Offline Support**: Fully functional offline via Service Worker (`sw.js`) and installable on desktop or mobile devices.
- **Question Palette**: Interactive palette providing quick navigation to any question with color indicators for answered, current, and unvisited states.
- **Review Mode**: View comprehensive results with correct and user-selected options highlighted in clean red/green visual cues.

## Setup & Deployment
1. Serve the application directory using any static Web Server (e.g., `npx serve`, Live Server, GitHub Pages, or Netlify).
2. Open `index.html` in any modern web browser.
3. Tap "Install" on Chrome/Safari/Edge to add the app to your Home Screen.
